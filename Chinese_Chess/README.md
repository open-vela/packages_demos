# Chinese_Chess
Chinese_Chess 是一款基于 OpenVela 系统设计的中国象棋游戏。

## 核心功能
1. 点击棋子选择棋子，再次点击棋盘位置，控制棋子移动。  
2. 车、马、炮、象、士、帅、兵棋子可以按照中国象棋的规则移动。  
3. 棋子可以互相吃子。  
4. 吃掉敌方阵营的帅/将后，游戏结束。
