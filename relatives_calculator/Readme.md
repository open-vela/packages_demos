## V0版本

亲戚计算器靠的是遍历来实现的，主要要思路如下：
案件按下后，在关系链表中添加对应关系
计算过程就是在关系树中遍历对应的关系。

问题如下：
1. 每个关系都要在树中添加节点，有些关系是不只在树的一个分支下，而是有着多个分支，因此关系树就会过于臃肿
接下来有两个任务
裁剪关系树，将关系树的分支尽可能减小。
化简表达式。

解决方式：
通过状态转移的方式来进行。
我理解为实时计算，通过状态转移的方式来进行

self
relation_tree /* 通过这个树来进行状态转移 */
